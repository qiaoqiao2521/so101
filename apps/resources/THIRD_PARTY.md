# Third-party sources

This project starts from the official Astro Starlight starter, generated using create-astro 5.3.0.

- Astro: https://github.com/withastro/astro — MIT.
- Starlight: https://github.com/withastro/starlight — MIT.
- Starlight provides routing, documentation layout, mobile navigation and Pagefind integration.
- Installed packages retain their licenses. Exact dependency versions and integrity hashes are in package-lock.json.
- Public resource links point to the respective authors. Linking does not relicense those projects or include them in a paid bundle.
- No proprietary workbench bundles or reverse-engineered code are part of this resource site.
