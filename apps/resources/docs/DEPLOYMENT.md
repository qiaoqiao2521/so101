# 资料站部署模板

网站使用独立的静态发布流程：

`robot.muqiao.fyi` → 专用 Cloudflare Tunnel → Nginx 回环监听 → 站点发布目录的 `current` 链接。

合并源代码后，现有域名与线上文件保持原状。发布只改变新版本静态产物的来源目录，不要求变更 DNS、隧道或机器人服务。实际服务器连接、Cloudflare 资源 ID 与凭据继续保存在授权的私有运维记录中。

## 从主仓库构建

1. 在 `apps/resources/` 执行 `npm ci` 与 `npm run check:content`。
2. 执行 `npm run build` 与 `npm run check:build`。
3. 使用 production preview 核对中文全文搜索、组合筛选、URL 恢复和移动端导航。
4. 给 `dist/` 生成部署清单，包含主仓库提交、应用目录、页面和静态资源清单。
5. 将产物复制到本网站独立的版本目录，在服务端核对文件数量、页面和资源路径。
6. 原子更新网站 `current` 链接，核对源站和公网页面、搜索脚本、部署清单。

模板在 `../infra/`。隧道令牌由系统凭据机制提供，模板仅引用令牌文件路径，不包含令牌值。

## 保持 URL 与回滚

本站当前在域名根路径运行；原路径 `/so101/`、`/fishbot/`、`/delivery/`、`/sources/`、`/_astro/` 与 `/pagefind/` 应继续可用。单仓库不要求单域名、单端口或单个服务进程。

每次发布保留上一版本。回滚时核对上一版本清单，然后原子切回 `current`。静态版本回滚不需要修改 DNS 或隧道，也不改变其他现有网站与机器人服务。
