本站公开官方资源入口与原创学习说明，任何访客都可以直接阅读。官方资源的版权与使用条件属于原作者。

如果你已在闲鱼与沐桥沟通资料整理或协助服务，请回到原闲鱼会话，确认本次订单的具体内容。本站不提供通用付款入口，也不代表某个订单已经包含全部资料或服务。

## 付款前对齐这些内容

| 核对项 | 应明确的内容 |
| --- | --- |
| 学习目标 | SO101 装配、模型查看、FishBot 仿真或导航等具体目标 |
| 资料清单 | 文件名称、数量、格式与版本；区分官方链接和原创整理 |
| 软件环境 | 操作系统、CPU 架构、ROS 或 LeRobot 版本、所需依赖 |
| 硬件范围 | 是否需要机器人、控制板、相机、雷达等设备 |
| 服务范围 | 是否包含讲解、安装协助、答疑；约定次数与时间范围 |
| 使用权限 | 是否允许修改、再分发或商业使用；分别核对第三方条款 |
| 交付方式 | 在原会话约定具体文件、发送方式与核对方法 |

## 收到资料后怎样核对

1. 对照约定清单检查文件是否齐全。
2. 核对文件格式与软件版本。
3. 打开说明文档，确认入口和依赖。
4. 按约定的小目标检查结果。
5. 将缺项、版本差异或无法打开的文件反馈到原闲鱼会话。

模型文件可以打开、环境可以启动、任务可以完成，是不同的交付结果。请在购买前写清本次需要核对哪一层结果，避免把资料包理解为任何设备上都能直接运行的完整系统。

## 关于第三方资料

本网站不打包转售第三方课程、固件或模型。特别是 [FishBot micro-ROS 运动控制仓库](https://github.com/fishros/fishbot_motion_control_microros)，其 README 明示未经授权不得商用。若订单涉及第三方材料，应先确认授权与具体使用范围。
