FishBot 适合串起移动机器人学习中的模型、驱动、传感器、建图与导航。先选自己的机器人型号和配套版本，再沿对应教程学习。

## 官方入口怎么选

| 入口 | 用途 | 阅读重点 |
| --- | --- | --- |
| [FishBot 建模与仿真](https://github.com/fishros/fishbot) | 课程配套的机器人建模与仿真源码 | README、分支与依赖 |
| [FishBot 建图与导航](https://github.com/fishros/fishbot_nav) | 移动机器人上位机源码 | 机器人型号、ROS 发行版与启动配置 |
| [micro-ROS 运动控制](https://github.com/fishros/fishbot_motion_control_microros) | 了解配套控制板的底层程序 | 板卡、通信方式与使用限制 |

运动控制仓库 README 明示未经授权不得商用。本站提供原仓库导航；第三方程序、课程和资料的使用范围以原作者说明为准。

## 建议阅读顺序

1. 阅读[环境准备](/fishbot/environment/)，对齐系统、ROS 与仓库分支。
2. 学习 ROS 2 节点、话题、消息与 TF。
3. 阅读建模与仿真资料，观察机器人坐标和传感器位置。
4. 阅读[建图与导航](/fishbot/navigation/)，区分地图、定位、规划和控制。

只有电脑时，可以先学概念与仿真。已经有套件时，优先采用套件对应的官方说明。导航示例启动成功，不等于你的底盘、雷达和固件已经完成适配。

## 怎样判断该学下一步

把每阶段目标写成一个可以观察的结果：能解释消息从哪里来、能看懂坐标关系、能说明定位与规划各自负责什么。出现故障时，先定位是哪一层的问题，再决定是否改参数。
