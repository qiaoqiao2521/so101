先从[官方仿真文件说明](https://github.com/TheRobotStudio/SO-ARM100/blob/main/Simulation/README.md)开始。该目录说明包含 SO101 的 URDF 与 MJCF 文件；下载后仍需按说明核对依赖与版本。

## 四种文件分别解决什么

| 格式 | 适合做什么 | 还需要什么 |
| --- | --- | --- |
| STL | 查看表面形状、准备打印 | 零件用途与打印参数 |
| STEP | 在 CAD 中查看与修改结构 | 单位、配合与加工核对 |
| URDF | 描述连杆与关节 | 对应显示工具或仿真接入 |
| MJCF | 描述 MuJoCo 场景与动力学 | MuJoCo 环境、控制与任务定义 |

需要看结构时，先看结构文件。需要研究关节运动或接触时，再选仿真器。不要为查看一个零件先安装整套学习框架。

## 三个值得保留的检查结果

1. 记录加载结果：文件是否完整，网格路径是否正确。
2. 记录运动结果：关节方向、范围与零位是否符合预期。
3. 记录交互结果：碰撞、接触和物体运动是否符合任务条件。

这三个结果层层递进。画面显示正常只说明模型能够显示。夹爪闭合的动画也不能单独证明抓取成功；抓取任务还需观察物体接触、抬升与保持。

## 下一步读什么

- 阅读 [MuJoCo 概览](https://mujoco.readthedocs.io/en/stable/overview.html)，理解模型、状态与控制。
- 阅读 [MuJoCo 建模指南](https://mujoco.readthedocs.io/en/stable/modeling.html)，核对关节、惯性和碰撞参数。
- 阅读 [OMPL 官方文档](https://ompl.kavrakilab.org/)，了解采样式运动规划。规划器仍需要机器人状态空间与有效性检查。

仿真适合观察与比较方案。将结果转移到实机前，还要核对尺寸、关节限制、控制频率和硬件差异。本站不把仿真结果作为实机能力证明。
