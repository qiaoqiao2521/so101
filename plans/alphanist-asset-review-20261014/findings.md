## 结果与资源的准确含义

98.2%对应20类单件共享策略的训练成功。十件任务使用按活跃件数另行训练/评测的策略，Table I十件为84%，并非该20类策略无改动串联十件。基线为64K环境、25K迭代、410 GPU-hours。全部为仿真，实体重复性和传感误差尚未证明。[§V及Table I](https://arxiv.org/html/2610.13354v1#S5)

学习机制除二元任务奖励与控制代价，还包括跨接近/持物/部分装配的reset缓存，以及成功导向采样。缓存决定可访问状态，采样决定练习分布；不能简化为只给奖励即可低成本自学。[§IV-B](https://arxiv.org/html/2610.13354v1#S4.SS2)

## SO101 接口合同

论文§IV-D采用Isaac Lab中的7轴Panda与平行夹爪；25Hz输出7维相对关节目标和1维夹爪命令，输入含本体状态、前一动作及零件/配合几何/机器人表面点云。[官方方法](https://arxiv.org/html/2610.13354v1#S4.SS4)

| 项目 | 当前SO101资产/缺口 |
| --- | --- |
| 本体与姿态 | 5轴手臂＋1爪，已做完整姿态筛选；少两个手臂自由度，不能保证Panda装配姿态可达 |
| 输出表示 | 当前执行器接收6维绝对位置目标；需要来源明确的相对动作锚点、尺度和关节顺序，不得补零/截断 |
| 夹爪 | 固定指＋转动指及0.15Nm仿真限幅；不能复制Panda夹爪、动力学或力矩上限 |
| 控制节拍 | 当前2ms积分/20ms控制；25Hz策略应独立核准40ms保持、时序与反馈，完整50Hz尚未验证 |
| 点云/状态 | 当前只提供完整物体几何上界与局部夹爪描述；缺配合件和动态机器人点云、坐标/裁剪/密度/归一化官方schema与真实传感验证 |
| 接触/成功 | 当前方块抓放、避障、释放、回位评分可复用；未建紧配合插入、齿轮、螺纹资产与独立装配判据 |
| 资源 | 本机4GB已跑当前模型；AlphaNIST大小/推理显存未知，不能据训练规模宣布本机可跑或不可跑 |
