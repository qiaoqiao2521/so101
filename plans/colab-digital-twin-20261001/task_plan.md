# Colab 数字孪生实验平台

## Goal / User intent

将毕业设计、答辩反思和中期报告副本归入 SO101 对应仓库，全部用 `.gitignore` 排除。数字孪生考虑两个方案，用户已指定先用 Colab CLI 搭建实验平台；方案二尚待用户说明，暂不替用户决定。

## Scope

- 保留下载原件；复制六份文件至 `local-documents/graduation-20260629/`，校验哈希和 Git 排除。
- 复用现有 MuJoCo 资产，在 Colab CPU 上做无头模型/轨迹/渲染实验并回收结果。
- 上传包采用模型/脚本的文件清单；个人材料、现场配置、标定和日志不得上传或提交。
- 本轮不连接实体机械臂；不展开 ROS 发行版迁移、视觉模型训练或新建平行仓库。

## Acceptance

1. 六份复制件哈希一致、`git check-ignore` 命中且 `git ls-files` 无新文件。
2. Colab 实际分配、安装、上传、执行、下载、释放流程有结果。
3. 6 秒物理仿真完成；六轴状态有限，合成指令受限，末端移动，生成 CSV、JSON、PNG、MP4。
4. 发布的源码不包含个人文档、生成结果或凭据，提交仅在 qiaoqiao2521/so101 既有远端内完成。
