# Findings

- Original [paper v1](https://arxiv.org/html/2609.40007v1#S3) and author project page agree on five guarded distal ellipsoids. Author project [pinned page](https://github.com/yathAg/multilink-safety-filter/blob/fd71a010c03a0bae4e797eefb6d9cce246b6cca0/index.html) still has Code coming soon; no released algorithm runtime to install directly.
- Barrier geometry is inherited from [AEGIS](https://github.com/THU-RCSCT/vlsa-aegis/tree/2457feed5968ae803926e178c8ce8243b9ecdcf9), MIT. Its coefficients are body-frame; MuJoCo Jacobians are world-frame. World left-multiplied rotation finite differences establish the correct angular coefficient sign.
- Paper §III-C explicitly limits its guarantee and executes nominal action when QP is infeasible. Local adaptation refuses such execution, includes an explicit known/estimated hazard translation velocity term, and filters joint targets without an underactuated end-effector pseudoinverse. These are deliberate differences.
- Paper protects gripper, wrist and forearm; upper arm/elbow remain outside its coverage. Local mesh envelopes are simulation estimates, not hardware calibration or functional safety certification.
- First vision input is a designated box plus registered depth; no Qwen/GroundingDINO/π₀.₅ model download. Tracker protects against stale/unsupported estimates by stopping; oracle obstacle trials must be labeled separately.
- MuJoCo `mj_step` integrates qpos after computing contacts; reading its contact array alone can miss the final 2ms integrated pose. Refresh `mj_forward` before measuring contact, including control boundaries and stopped/final states. The paired experiment now includes check count, actual physics steps and elapsed simulation time.
- Hard certificate checks and QP desired clearance share a risk when the sampled position servo does not realize predicted velocity exactly. Local adapter adds 6mm QP buffer outside the unchanged12mm hard margin; this is an empirical engineering reserve, not a derived robustness guarantee. Gradient auxiliary reference prevents a stale but positive plane from unnecessarily inhibiting the retreat scene; new certificate searches only accept verified current geometry.
- Rendered tracker covers visible points only: initial center offset15mm above true box center, held-step lag2.4mm. Adapter rejects this geometry by default rather than silently treating it as the full hazard.
- Final evidence and all retained failure boundaries are summarized in [RESULTS.md](../../experiments/multilink-safety/RESULTS.md); no result from the previous training task was used to claim safety-layer acceptance.
